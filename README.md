# FurniCalc

An open-source collection of practical furniture design and woodworking calculation tools.

## About

FurniCalc is designed to help furniture designers, woodworkers, makers, and DIY enthusiasts with common calculations used during the furniture design process.

The project provides simple, accessible, browser-based tools with no installation or dependencies required.

## Features

### 📏 Unit Converter
Convert dimensions between millimetres and inches.

### 🪵 Wood Volume Calculator
Calculate the volume of wood panels and solid wood pieces using length, width, and thickness.

### 🛋️ Sofa Width Calculator
Estimate recommended sofa seating width based on the number of seats and width per person.

## Getting Started

Simply open the `index.html` file in any modern web browser.

No installation or dependencies are required.

## Technologies

- HTML5
- CSS3
- JavaScript

## Project Goals

FurniCalc aims to build a growing collection of free and practical tools for furniture designers and woodworkers.

Future features may include:

- Cutting list calculator
- Material cost calculator
- Sheet material calculator
- Furniture ergonomics reference
- Chair and table dimension guides
- Woodworking measurement tools
